## これはなに？

Reina_Sakiria が、無線で、軽量で、ライトハウス (or 優れた outside in な体と同じトラッキング方式)で OSS な HMD を実現したいなって思って ... !

その足掻きの軌跡になるかも知れないし、実用品になるかも知れない。

Reina_Sakiria の AI しばきのサイドプロジェクトってわけ

（ちなみに ... もともとは既存のものをあまり使わない方針だったからこの名前がついてるんだけど、状況が変わって都合の良いものが揃ってきたから、 LLFA-Link というアプリやツールじゃなくて、 LLFA-Link-Project っていう抽象度高い名前付けになったのよね ... ）
